## 📚 1. คลังคู่มือแยกเฉพาะแต่ละสายงาน (Dedicated Career Guides)

แต่ละเล่มจะเจาะลึกเฉพาะสายงานนั้นๆ 100% ครบทั้งวงจรการผลิต, แผนที่ GPS, ความจุกระเป๋ารถ, จุดคุ้มทุน, และสูตรเร่งผลผลิต:

* 🌸 **[คู่มือคัมภีร์ฟาร์มดอกไม้ฉบับสมบูรณ์ (FLOWER_FARMING_MASTER_GUIDE.md)](file:///C:/Users/_newgen/Documents/antigravity/epic-euclid/docs/FLOWER_FARMING_MASTER_GUIDE.md)**
  * แผนที่และรูทโลจิสติกส์ 5 เส้นทาง (เกรปซีด ➔ ตาก ➔ จัดช่อ ➔ หาดเวสปุชชี)
  * การส่งโรงพยาบาล ($100/ดอก) จบใน 52 นาที vs จัดช่อส่งหาดเวสปุชชี ($387)
  * การคำนวณและจุดคุ้มทุนของการเปิดคูณ 120k และกฎเหล็ก "สูบใส่ตู้"
* 🐷 **[คู่มือคัมภีร์ฟาร์มหมูฉบับสมบูรณ์ (PORK_FARMING_MASTER_GUIDE.md)](file:///C:/Users/_newgen/Documents/antigravity/epic-euclid/docs/PORK_FARMING_MASTER_GUIDE.md)**
  * วงจรการผลิต 15 นาที/รอบ, การคิดต้นทุนซื้อข้าว 100 บ., และจุดคุ้มทุน
  * ผ่าลึก 5 โมเดลกลยุทธ์ (Ultra-AFK ขายดิบคน, โพรขาย $194, แพ็คขาย $422, โรงงานรับซื้อ $130, ไฮบริด)
  * เทคนิค The Rice Stash Trick และ Dual-Timer

## 📊 2. ศูนย์เปรียบเทียบข้ามสายงาน (Cross-Career Benchmark)

สำหรับผู้เล่นที่ต้องการเปรียบเทียบว่า **อาชีพไหนทำเงินดีที่สุด เหนื่อยน้อยที่สุด หรือคุ้มค่าเวลาที่สุด**:

* 📊 **[ศูนย์วิเคราะห์เปรียบเทียบข้ามสายงาน (CROSS_CAREER_BENCHMARK.md)](file:///C:/Users/_newgen/Documents/antigravity/epic-euclid/docs/CROSS_CAREER_BENCHMARK.md)**
  * ตารางเปรียบเทียบต่อ 1 คันรถบรรทุก (150 กก.) ระหว่าง ดอกไม้ vs หมู vs เหล็ก
  * เปรียบเทียบผลลัพธ์ในเวลาทำงาน 1 กะเท่ากัน (7.4 ชั่วโมง)
  * ศึกมาราธอนระยะยาว 48 - 72 ชั่วโมง
  * การจัดอันดับ Tier List ความคุ้มค่าในเซิร์ฟเวอร์
