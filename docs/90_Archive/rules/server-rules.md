## 📜 ข้อบังคับหลักของเมือง RUN TOWN

เซิร์ฟเวอร์ RUN TOWN ให้ความสำคัญกับความสมดุลของการ Roleplay และความปลอดภัยของผู้เล่นใหม่

---

## 🟢 1. พื้นที่ Safe Zone (เขตปลอดภัย 100%)
* **โรงพยาบาล Pillbox Hill:** ห้ามชักอาวุธ, ห้ามทำร้ายร่างกาย, ห้ามก่อวินาศกรรมทุกกรณี
* **สถานีตำรวจ Mission Row (LSPD):** ห้ามบุกชิงตัวประกันโดยไม่มีการเปิดสตอรี่ล่วงหน้า
* **บทลงโทษ:** การฝ่าฝืนมีโทษจำคุกโอซี (OC Jail) 60-180 นาที

---

## 🔴 2. พื้นที่ Red Zone (เขตทะเลทรายเรเบล)
* เป็นพื้นที่ไร้ขื่อแป อนุญาตให้เกิดการชิงทรัพย์และสู้รบระหว่างกลุ่มได้
* ตำรวจไม่รับแจ้งความในเขตพื้นที่สีแดง
* **คำแนะนำผู้เล่นทำงานขาว:** ห้ามขับรถขนหมูหรือพืชผลทางการเกษตรผ่านเขตนี้เด็ดขาด

---

## ⚠️ 3. กฎการดักปล้นผู้เล่นสายฟาร์ม
* ห้ามดักปล้นที่จุดมาร์กเกอร์ฟาร์มหรือจุดส่งของโดยตรง
* ต้องเปิดสตอรี่และแจ้งเตือนให้อีกฝ่ายยอมจำนนก่อนอย่างน้อย 15 วินาที
* ห้ามยิงหรือทำร้ายร่างกายหากผู้เสียหายให้ความร่วมมือ
